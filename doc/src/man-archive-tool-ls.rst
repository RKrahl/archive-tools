archive-tool ls
===============

Synopsis
~~~~~~~~

*archive-tool ls* [--format {ls,checksum}] [--checksum <checksum>] <archive>

Description
~~~~~~~~~~~

.. program:: archive-tool ls

List the content of an archive.

Options
~~~~~~~

.. program:: archive-tool ls

.. option:: --format {ls,checksum}

    Select the output style.

.. option:: --checksum <checksum>

    Select the checksums to display on `--format checksum`.

.. option:: <archive>

    Path to the archive.
