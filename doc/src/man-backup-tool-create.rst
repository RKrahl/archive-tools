backup-tool create
==================

Synopsis
~~~~~~~~

*backup-tool create* [--policy <policy> | --user <user>]

Description
~~~~~~~~~~~

.. program:: backup-tool create

Create a backup.

Options
~~~~~~~

.. program:: backup-tool create

.. option:: --policy <policy>

    Select the policy.

.. option:: --user <user>

    Select a user.  This implies `--policy user`.
